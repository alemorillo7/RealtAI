# RealtAI CRM

Una plataforma CRM corporativa avanzada impulsada por IA para la gestión de mensajes, agentes y procesos inmobiliarios.

## Identidad Visual
- **Colores**: Azul Profundo, Oro Dorado y Verde Esmeralda.
- **Tipografía**: Montserrat (Títulos), Inter (Cuerpo) y Space Grotesk (Acentos).

## Tecnologías
- **Frontend**: Next.js 15+
- **Backend**: Firebase (Auth, Firestore, Storage)
- **Estilos**: Tailwind CSS 4

## Configuración

1. Clona el repositorio.
2. Configura las variables de entorno en `.env.local`.
3. Instala las dependencias:
   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
